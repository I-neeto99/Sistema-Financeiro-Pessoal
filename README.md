Sistema Financeiro Pessoal

Sistema web para controle financeiro pessoal, desenvolvido do zero como projeto de estudo prático em back-end com Java e Spring Boot — e que também nasceu de uma necessidade real: organizar meus próprios gastos, incluindo o controle financeiro do meu trabalho na área administrativa de uma empresa familiar do setor de construção.

 Sobre o projeto

Mais do que um exercício de portfólio, este projeto resolve um problema real: registrar receitas e despesas de forma simples, categorizada, e sem depender de planilhas manuais. A ideia é evoluir para uma ferramenta que eu realmente uso no dia a dia — tanto para finanças pessoais quanto para apoiar o controle de gastos da empresa onde trabalho.

 Funcionalidades
Cadastro, listagem e exclusão de transações financeiras (receitas e despesas)
Categorização de transações (ex: Mercado, Salários, Transporte)
Validação de regras de negócio (ex: valores inválidos são rejeitados)
API REST testada e documentada via Postman
 Tecnologias
Back-end: Java + Spring Boot (Spring Web, Spring Data JPA)
Banco de dados: PostgreSQL
Front-end: HTML, CSS e JavaScript puro (em desenvolvimento)
Ferramentas: Maven, Lombok, Postman, Git/GitHub
